# Web Programming Lab – Lab 0

This repository contains **Lab 0 programs** for the Web Programming course.  
The experiment focuses on understanding and implementing **basic HTML, CSS, and JavaScript concepts**.

---

## Aim

To design and develop basic web pages using HTML and CSS by implementing commonly used HTML tags such as text formatting, images, links, lists, tables, semantic elements, multimedia elements, and forms, and to apply basic styling and interactivity for better presentation and usability.

---

## Programs Included

The repository contains the following programs:

1. **Form Creation and Validation**
   - Creation of a form using HTML
   - Client-side validation using JavaScript

2. **College Information Page**
   - Use of semantic tags like header, footer, section, article, and nav
   - Text formatting, lists, and tables

3. **Image Map Program**
   - Use of image, map, and area tags
   - Demonstration of rect, circle, polygon, and default areas

4. **Table with Meter and Progress**
   - Table creation using rowspan, colspan, caption
   - Styling using CSS
   - Meter and progress elements

5. **FAQ and Dialog Program**
   - Use of details and summary tags
   - Dialog box using JavaScript

6. **Multimedia and Ruby Text**
   - Audio and video tags with source and track
   - Ruby, embed, and other HTML5 elements

---

Thus, the required web pages including a form page and other web pages using HTML and CSS (with minimal JavaScript wherever required) were successfully created and executed, and the output was verified in a web browser.
